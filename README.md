# 🚀 Hono + Bun Starter

Starter project sederhana menggunakan **[Hono](https://hono.dev/)** (web framework minimalis) dan **[Bun](https://bun.sh/)** (JavaScript runtime super cepat).  
Project ini cocok untuk belajar REST API, middleware, dan deployment dengan Bun.

---

## 📂 Fitur

- **Hono Framework** → web framework ringan dengan sintaks mirip Express.
- **Bun Runtime** → cepat, built-in bundler & transpiler.
- **Authentikasi** → jwt + refresh token + email verifikasi

## 🛠️ Instalasi

### **1. Clone Repository**

```bash
git clone https://github.com/aliefmagicq/hono-bun-restfulapi.git
cd hono-bun-starter
```

Untuk install dependencies ⬇️:

```sh
bun install
```

Untuk run:

```sh
bun run dev
```

open http://localhost:3000
